# Proximity Sensor Disabler Magisk Module

## Descriptions
Disables proximity sensor or disables proximity fusion sensor or removes android.hardware.sensor.proximity feature systemlessly.

## Changelog

## Requirements
Magisk or Kitsune Mask or KernelSU or Apatch installed

## Installation Guide & Download Link
- Install this module https://github.com/reiryuki/Proximity-Sensor-Disabler-Magisk-Module via Magisk app or Kitsune Mask app or KernelSU app or Apatch app or Recovery if Magisk or Kitsune Mask installed
- Reboot
